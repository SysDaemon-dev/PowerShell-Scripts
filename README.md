# PowerShell-Scripts · SysDaemon.dev

Praxiserprobte PowerShell-Skripte aus dem Enterprise-IT-Alltag: Intune, SCCM, PSADT, Windows Server, Active Directory und Support-Automatisierung.

## Aufbau
- Jedes Skript liegt als `.ps1`-Datei im Repository.
- Der Kommentarblock oben (`.SYNOPSIS`, `.DESCRIPTION`, `.NOTES` mit `Tags:` und `Module:`) wird automatisch auf [SysDaemon.dev](https://github.com/SysDaemon-dev) übernommen.

## Hinweis
Alle Skripte vor dem Einsatz in einer Testumgebung prüfen. Verwendung auf eigene Verantwortung.
